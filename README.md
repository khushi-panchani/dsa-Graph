## 📖 Key Concepts Learned

* A graph consists of vertices (nodes) and edges.
* An adjacency list stores all neighbouring vertices of each vertex.
* An undirected graph has bidirectional connections.
* STL `list` can be used to store adjacent vertices.
* `push_back()` inserts a connected vertex into the adjacency list.
